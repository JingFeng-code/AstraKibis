# AstraKibis 品牌與介面規範（v0.1）
定位：輕量自架資源探索工具；Little treasures, gathered daily.
命名靈感：Kibisis（神話中的袋子）衍生品牌名，非宣稱原名。圖標以小型束口袋與星形寶藏表示日常收集。不是原版雷達圖案。
色彩：墨藍 #223449、紙白 #fffdf8、暖米 #f5f1e8、金色 #e8c78d、互動藍 #365875。
品牌標誌：docs/logo.svg、src/web/public/favicon.svg 同源；可縮放 SVG，無外部字體或圖片依賴。
設計：保留已驗收的搜尋、頻道、收藏、管理、行動版與深色模式，加入品牌識別、引導區與暖色閱讀介面。尚需瀏覽器桌面/手機截圖驗收、對比檢查及使用者確認。不是完整 UX 重構。
