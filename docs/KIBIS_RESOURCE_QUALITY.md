# AstraKibis v0.3 資源品質 MVP
- 不修改 SQLite schema：依標題及前 1200 字摘要產生可重算的 ResourceQuality，SQL 與 API 共用規則；原始資料、收藏與上游欄位不變。
- 八種免費類型、台灣適用性文字線索、信用卡需求、超額收費線索、原文證據、verifiedAt=null。不得將關鍵字或來源地區等同官方資格；未知一律保留。
- 資源清單與動態資訊分流；四個 GitHub 靜態清單仍可搜尋、收藏，但不進台灣熱點、新日報及週報。首頁預設「優先動態資訊」排序，可用資訊類型篩選；既有最新排序仍保留。熱點推薦每來源最多兩筆，統計不截斷；明確其他地區限定的免費或優惠項目不進推薦、新日報及週報，原始收錄仍可查。
- Steam 台灣設定使用 cc=tw / l=tchinese，不代表每一項遊戲都可在台灣領取。
- 價格明示為既有人民幣估算；未引入即時匯率或假裝新台幣。費用篩選仍沿用上游人民幣單位。
- 依賴稽核僅報告，不自動升級；Nodaroo npm 安裝樹可能與 CI pnpm 不同。HTTPS 尚未處理。
- 待完成：官方逐筆查證及驗證日期、人工覆寫、完整來源可信度與額度模型、真正新台幣價格、跨源權重、八領域導覽、正式機備份演練。
- 台灣版 34 個候選來源與 88 個預設停用來源仍維持；不新增未查證 RSS，不增加付費服務。
